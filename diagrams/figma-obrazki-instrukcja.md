# Kopiowanie obrazków kawy z Figmy

## Krok po krok:

### 1. **Otwórz Figmę:**
```
1. Idź na: https://www.figma.com/file/SAoBmuOqTfguehdT4IFRxQ/Coffee-House
2. Kliknij strzałkę obok nazwy → "Duplicate to your drafts"
3. Otwórz swoją kopię (będzie miała "In Drafts")
```

### 2. **Znajdź sekcję z kawami:**
```
1. Przewiń do sekcji "Choose your favorite coffee"
2. Zobaczysz 3 karty z kawami w karuzeli
3. Każda karta ma zdjęcie kawy u góry
```

### 3. **Zaznacz pierwszy obrazek:**
```
1. Kliknij na zdjęcie kawy w pierwszej karcie
2. Obrazek zostanie zaznaczony (niebieska ramka)
3. Sprawdź czy to tylko obrazek, nie cała karta
```

### 4. **Eksportuj obrazek:**
```
1. Prawy panel → sekcja "Export"
2. Kliknij "+" jeśli nie ma ustawień eksportu
3. Wybierz format: JPG
4. Rozdzielczość: 2x (dla Retina)
5. Kliknij "Export coffee-image"
```

### 5. **Zapisz plik:**
```
1. Zapisz jako: coffee-1.jpg
2. Lokalizacja: twój folder assets/
3. Powtórz dla pozostałych obrazków
```

### 6. **Powtórz dla wszystkich:**
```
coffee-1.jpg - S'mores Frappuccino
coffee-2.jpg - Caramel Macchiato  
coffee-3.jpg - Ice coffee
(i tak dalej dla wszystkich produktów)
```

## Alternatywna metoda - kopiuj bezpośrednio:

### **Jeśli Export nie działa:**
```
1. Kliknij prawym na obrazek
2. "Copy as" → "Copy as PNG/JPG"
3. Wklej do programu graficznego (Paint, Photoshop)
4. Zapisz jako coffee-1.jpg w folderze assets/
```

## Szybka metoda - wszystkie naraz:

### **Zaznacz wiele obrazków:**
```
1. Trzymaj Ctrl i klikaj na obrazki
2. Wszystkie zaznaczone obrazki
3. Export → JPG → 2x
4. Figma wyeksportuje wszystkie jako ZIP
5. Rozpakuj i przemianuj pliki
```

## Rozmiary obrazków:

### **Zalecane wymiary:**
```
- Szerokość: 300-400px
- Wysokość: 200-300px  
- Format: JPG (mniejszy rozmiar)
- Jakość: 80-90% (dobry kompromis)
```

## Troubleshooting:

### **Jeśli nie widzisz opcji Export:**
```
1. Sprawdź czy masz dostęp do pliku
2. Spróbuj odświeżyć stronę Figmy
3. Zaloguj się ponownie do Figmy
```

### **Jeśli obrazki są za małe:**
```
1. Zmień rozdzielczość na 3x lub 4x
2. Lub znajdź większe wersje w innych sekcjach Figmy
```

### **Jeśli nie możesz znaleźć obrazków:**
```
1. Użyj Ctrl+F w Figmie
2. Szukaj "coffee" lub "favourite"
3. Sprawdź różne strony w projekcie
```
